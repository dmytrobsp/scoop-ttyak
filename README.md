# Scoop bucket for ttyak

[ttyak](https://github.com/dmytrobsp/ttyak) is a native Slack client for the terminal.

```powershell
scoop bucket add ttyak https://github.com/dmytrobsp/scoop-ttyak
scoop install ttyak
```

The manifest is updated by ttyak's release workflow on every release; please report problems at
https://github.com/dmytrobsp/ttyak/issues.
